# Қазақша есептердің аударма материалдары

**ВКТУ · Есімханова Аружан Түсіпханқызы · 25-ИСТК-2о.**

[kk.json](kk.json) файлында алты есептегі мәтіндік блоктардың бастапқы нұсқасы мен қазақша аудармасы берілген. Бұл файл аударманың толықтығын және терминдердің бірізділігін салыстыруға арналған. `reports` өрісі мәтін қолданылатын есептерді көрсетеді. `preserveOriginal` белгісі API жауабының дәл мәтінін өзгеріссіз сақтау қажеттігін білдіреді.

Негізгі терминдер: «зертханалық жұмыс», «дерекқор», «сұрау», «жауап», «құрастыру», «атауы бар том», «қақтығыс», «құпиясөз», «экран суреті». Бағдарламалар мен әдістердің атаулары, маршруттар, файл жолдары және GitHub интерфейсіндегі тексеруге қажет атаулар сақталған.

Техникалық дәлелдер аудармаға сәйкестендіріліп өзгертілген жоқ. Командалар, код, журналдар, API жауаптары мен суреттер бастапқы күйінде берілген; олардың айналасындағы түсіндірмелер қазақша жазылған. Құпиясөздің мысалдық орны және есеп авторы құрастырған қорытынды санауыштарының атаулары қазақшаланған. PR пікірінің қазақша мазмұны бөлек белгіленіп, бастапқы пікірге сілтеме сақталған.

[validation.json](validation.json) файлында PDF өлшемдері, SHA-256, беттер саны және орындалған құжат тексерулері жазылған. Қолданба тестілері аударма кезінде қайта орындалған жоқ; бұрынғы тест нәтижелері өзгеріссіз сақталған.
