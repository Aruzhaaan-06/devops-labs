Алты есептің жалпы көлемі - **47 бет**. Түсіндірмелер, сұрақтарға жауаптар, қорытындылар, кесте атаулары және сурет жазулары қазақ тіліне аударылған. Барлық есепте университет, толық аты-жөні және топ көрсетілген. GitHub сілтемелері басу арқылы ашылады.

Командалар, код, нақты API жауаптары, журналдар және шынайы экран суреттеріндегі мәтін дәлел ретінде бастапқы тілінде сақталған. Мысалы, API қатесінің орысша мәтіні өзгертілмейді: оның мағынасы қазақша түсіндіріледі. Аударма техникалық нәтижелерді немесе орындалу мәртебесін өзгертпейді.

## Толық тапсыру үшін қажет материалдар

- **1-зертханалық жұмыс:** Postman коллекциясының экран суреті, Visual Studio жөндегішінде Locals / Call Stack арқылы екі сұрауды қолмен орындау және Test Explorer-дегі міндетті 24 тестінің суреті.
- **2-зертханалық жұмыс:** Docker Desktop → Settings → General бөліміндегі WSL 2 қосылғанын көрсететін шынайы сурет. Құрастырулар мен контейнер тексерулері [сақталған нәтижелерде](../evidence/lab02/README.md) бар.
- **3-зертханалық жұмыс:** PostgreSQL қолданылуын көрсететін Visual Studio консолі мен Test Explorer суреттері. [PostgreSQL дәлелдері](../evidence/lab03/README.md) және [Compose дәлелдері](../evidence/lab03-compose/README.md) сақталған; Adminer суреттері есепке енгізілген.
- **4-зертханалық жұмыс:** оқытушының GitHub атауы белгілі болғанда оны collaborators қатарына қосу; екі жеке тіркелгіні топтас студенттің орнына пайдалануды келісу. Бөлек B репозиторийіндегі кезең орындалмаған. Қабылданбаған push үшін дәл мәтіндік шығыс бар, бірақ терминал терезесінің бөлек суреті жоқ. [Толық күйі мен дәлелдері](../evidence/lab04-git/README.md).
