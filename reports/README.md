`source/` мазмұны және `assets/` суреттері қайта құруға жеткілікті. PDF ішінде код пен журнал бастапқы тілінде сақталады. Қаріп файлдары лицензиясына байланысты қосылмаған.

[lab01-source.zip](lab01-source.zip) - бірінші жұмыстың тарихи код мұрағаты; қазіргі барлық кезеңнің коды репозиторий түбірінде. [translation/](translation/README.md) алғашқы алты есептің бұрынғы аударма салыстыруын сақтайды; оның ескі бет саны мен SHA мәндері жаңа тексеру нәтижесі емес.

Рәсімдеу кемшіліктері түзетілгенімен, [жетіспейтін UI дәлелдері, оқытушы келісімдері және қорғау](../docs/REPORT_COMPLETENESS.md) ашық қалады. Есептер толық қабылданды немесе 70+ бағаға кепілдік берілді деп мәлімделмейді.
