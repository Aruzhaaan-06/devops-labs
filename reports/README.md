Он төрт есептің жалпы көлемі - **116 бет**. Бұрынғы алты есеп қазақ тіліне аударылған, 08-15-материалдардың жаңа есептері қазақша жазылған. Түсіндірмелер, сұрақтарға жауаптар, қорытындылар, кесте атаулары және сурет жазулары қазақ тілінде. Барлық есепте университет, толық аты-жөні және топ көрсетілген. GitHub сілтемелері басу арқылы ашылады.

09-материалдың [PR #17-і](https://github.com/Aruzhaaan-06/devops-labs/pull/17) 10-материалдың басында біріктірілді. 10-материалдың есебі 349a0b1 функционалдық кезеңінің өлшемдерін тіркейді; оны жариялағаннан кейінгі соңғы main мен API сәйкестігі [v1.0.0 релизіндегі](https://github.com/Aruzhaaan-06/devops-labs/releases/tag/v1.0.0) `lab10-final-verification.json` файлы арқылы беріледі. 10-материал қосылған кезде алдыңғы сегіз PDF өзгертілмеді; 11-материалды қосу кезінде алдыңғы тоғыз PDF-тің мазмұны да сақталды. 11-материалдың жергілікті тәжірибелері мен соңғы deploy сәйкестігі бөлек `lab11-final-verification.json` файлы арқылы беріледі.

12-материал қосылған кезде алдыңғы он PDF-тің мазмұны өзгертілмеді. Оның соңғы main/API сәйкестігі `lab12-final-verification.json` файлы арқылы беріледі; v1.0.0 релизіндегі бұрынғы архивтер өзгертілмейді.

13-материал қосылған кезде алдыңғы он бір PDF өзгертілмеді. Соңғы main/API сәйкестігі `lab13-final-verification.json` арқылы беріледі. Есепте Target health пен төрт жеке PromQL графигі, Grafana, cAdvisor және Dozzle шынайы суреттері бар.

14-материал қосылған кезде алдыңғы он екі PDF өзгертілмеді. Соңғы main/API сәйкестігі `lab14-final-verification.json` арқылы беріледі. Браузерді басқару рұқсаты болмағандықтан UI экспорт және ақаулар кезінде Grafana/Dozzle интерфейсін автоматты қарау орындалмады; нақты API жауаптары мен Docker журналдары сақталды. Есепте сәтсіз алғашқы OOM әрекеті бөлек сипатталған.

15-материал қосылған кезде алдыңғы он үш PDF өзгертілмеді. Жаңа v1.1.0 релизінде есеп, ортақ мұрағат және `lab15-final-verification.json` жарияланады. Есептің графигі нақты Prometheus деректерінен құрылған, UI скриншоты емес. Он минуттық онлайн қорғау мен СДО-ға жүктеуді студент орындайды.

Командалар, код, нақты API жауаптары, журналдар және шынайы экран суреттеріндегі мәтін дәлел ретінде бастапқы тілінде сақталған. Мысалы, API қатесінің орысша мәтіні өзгертілмейді: оның мағынасы қазақша түсіндіріледі. Аударма техникалық нәтижелерді немесе орындалу мәртебесін өзгертпейді.

## Толық тапсыру үшін қажет материалдар

- **1-зертханалық жұмыс:** Postman коллекциясының экран суреті, Visual Studio жөндегішінде Locals / Call Stack арқылы екі сұрауды қолмен орындау және Test Explorer-дегі міндетті 24 тестінің суреті.
- **2-зертханалық жұмыс:** Docker Desktop → Settings → General бөліміндегі WSL 2 қосылғанын көрсететін шынайы сурет. Құрастырулар мен контейнер тексерулері [сақталған нәтижелерде](../evidence/lab02/README.md) бар.
- **3-зертханалық жұмыс:** PostgreSQL қолданылуын көрсететін Visual Studio консолі мен Test Explorer суреттері. [PostgreSQL дәлелдері](../evidence/lab03/README.md) және [Compose дәлелдері](../evidence/lab03-compose/README.md) сақталған; Adminer суреттері есепке енгізілген.
- **4-зертханалық жұмыс:** оқытушының GitHub атауы белгілі болғанда оны collaborators қатарына қосу; екі жеке тіркелгіні топтас студенттің орнына пайдалануды келісу. Бөлек B репозиторийіндегі кезең орындалмаған. Қабылданбаған push үшін дәл мәтіндік шығыс бар, бірақ терминал терезесінің бөлек суреті жоқ. [Толық күйі мен дәлелдері](../evidence/lab04-git/README.md).

- **8-зертханалық жұмыс:** алерт/Grafana UI суреттері толықтырылмаған; браузерді басқару бұғатталды. Постмортем, нақты график және API деректері берілген. Курс форумында слотқа жазылу, экран көрсетіп екі сұраққа жауап беру және есепті СДО-ға жүктеу керек. Кеңейтілген performance baseline [#30](https://github.com/Aruzhaaan-06/devops-labs/issues/30) ашық қалады.
