# Есептердің өңделетін бастапқы файлдары

Негізгі дерек - UTF-8 JSON. Әр PDF-ке аттас `.json` файлы сәйкес келеді. Бұл DOCX емес, бірақ тәуелсіз өңдеуге және бірдей PDF-ті қайта құруға болатын бастапқы пішім. JSON ішіндегі HTML тәрізді қарапайым белгілер сілтеме мен екпінді сақтайды; толық веб-бет емес.

- `catalog.json`: университет, пән, студент, топ, оқу жылы және әр есептің мақсаты, теориясы, нәтижесі, талдауы және қорытындысы.
- `*-report.json`: бастапқы кезеңнен көшірілген абзацтар, тақырыптар, кестелер, код және сурет сілтемелері.
- `submission-summary-kk.json`: зертханалық жұмыс болып саналмайтын қорытынды есеп.
- `assets-manifest.json`: `reports/assets/` ішіндегі файлдардың SHA-256 мәндері және бастапқы атаулары.

Мазмұнды редакциялау кезінде `type: code` блоктарының мәтінін, API жауаптарын, SHA мәндерін және тәжірибе уақыттарын тек нақты негіз болғанда ғана өзгерту керек. `originalCommit` және `originalPdfSha256` өрістері көшіру басталған тарихи нұсқаны көрсетеді. Алғашқы алты есептің аударма салыстыруы `reports/translation/` ішінде сақталған; ол жаңа беттер санына арналған тексеру емес.

## Қайта құрастыру

Қажет: Python 3, ReportLab, pypdf, pdfplumber, Pillow; Windows жүйесіндегі Times New Roman және Consolas қаріптері. Қаріп файлдары лицензиясына байланысты репозиторийге қосылмайды. Басқа жүйеде өзіңіз заңды түрде алған `times.ttf`, `timesbd.ttf`, `timesi.ttf`, `consola.ttf` каталогын `--font-dir` арқылы көрсетіңіз. Қаріп үнсіз алмастырылмайды.

```powershell
python -m pip install -r scripts/requirements-reports.txt
python scripts/build_reports.py
python scripts/check_reports.py
```

Бір есепті қайта құру:

```powershell
python scripts/build_reports.py --only lab03-postgres-report
python scripts/check_reports.py
```

PDF құру желіге, қолданба API-іне немесе дерекқорға сұрау жібермейді. Бұл тәжірибені қайта орындау емес. Ескі `build-labNN-report.py` атаулары жаңа жинақтаушыға бағытталған үйлесімді кіру нүктелері ретінде сақталады.

Кесте жолы ұзын болса, келесі бетке бөлінуі мүмкін; бірінші жол қайталанады. Кодты визуалды тасымалдау бастапқы мәтінді өзгертпейді. Суретті алмастырғанда түпнұсқа дәлелін және файл хэшін сақтау керек; жоқ UI дәлелін ойдан жасауға болмайды.

`check_reports.py` PDF ашылуын, A4, мәтін шекарасын, бөлімдерді, 14 pt Times мәтінін, қаріптердің енгізілуін, бос беттерді, нөмірлерді, бастапқы мәтіннің және сурет пиксельдерінің сақталуын тексереді. Соңғы қадам - PDF-ті PNG-ге шығарып, титулды, кестелерді, суреттерді, кодты және соңғы бетті көзбен қарау.
