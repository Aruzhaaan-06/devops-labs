# Git және GitHub-та бірлескен жұмыс — орындалу дәлелдері

Д. Серікбаев атындағы Шығыс Қазақстан техникалық университеті · Есімханова Аружан Түсіпханқызы · 25-ИСТК-2о.

07-материал: main қорғауы, тікелей push қабылданбауы, PR-ға жолдық пікір, бөлек түзету коммиті, Approve, Board және екі тармақтағы нақты қақтығыс тексерілген. 13 техникалық тармақ расталған. Екінші аккаунт temirkhanerbolatovich-coder сол иеге тиесілі; тәуелсіз студент ревьюі ретінде көрсетілмейді. Оқытушының GitHub атауы белгісіз, жеке B репозиторийі кезеңі орындалмаған. Қабылданбаған push мәтіні сақталған, терминал суреті жоқ. Тарихи 7 беттік PDF кейін академиялық үлгімен қайта рәсімделген; бастапқы файл Git тарихында бар.
