# Тапсырмалар сервисінің API интерфейсі — орындалу дәлелдері

Д. Серікбаев атындағы Шығыс Қазақстан техникалық университеті · Есімханова Аружан Түсіпханқызы · 25-ИСТК-2о.

2026 жылғы 22 қазан. Бұл кезең InMemory режимінде орындалған. Бастапқы нұсқа: 22/22; міндетті статистика: 24/24; қосымша мерзім ережесі: 28/28. HTTP сценарийлері: міндетті 21 және соңғы 23 сұрау. Postman: 22 сұрау/67 тексеру және 24 сұрау/73 тексеру. Процесс қайта іске қосылғанда 4 жоба орнына 0 жоба қайтарылған. Кейінгі PostgreSQL нәтижелері lab03 каталогында бөлек берілген.

TRX қорытындылары нақты іске қосулардан алынған; компьютердің жеке метадеректері бар түпнұсқалар жарияланбаған. Swagger суреттері бар. Postman/Test Explorer суреттері және F9/F10/F11 арқылы Locals/Call Stack бақылауы әлі расталмаған. Код бойынша талдау қолмен жөндеуді алмастырмайды.
