# Тапсыруға дайындық дәлелдері

ВКТУ · Есімханова Аружан Түсіпханқызы · 25-ИСТК-2о.

2026 жылғы 25 қазан. [Тапсыру чек-парағы](../../docs/submission-checklist.md) · [TRX қорытындысы](checks.json).

[Қорытынды толықтыру PDF](../../reports/submission-summary-kk.pdf) - 3 бет, барлық беті PNG-ге шығарылып визуалды тексерілді; қазақ әріптері, кестелер және сілтемелер дұрыс көрсетіледі. Оны қайта құру: `python scripts/build-submission-summary.py` (ReportLab, pypdf және Windows Arial қаріптері). Бұл әрекет желіге немесе дерекқорға сұрау жібермейді.

Бөлек жұмыс көшірмелерінде InMemory 24/24, PostgreSQL міндетті 24/24 және толық 28/28 тест өтті. Әр жазбада бастапқы кодтың SHA мәні, нақты іске қосу уақыты және жергілікті TRX файлының SHA-256 мәні берілген. Жария қорытындыға компьютер атауы, пайдаланушы жолдары және құпия қосылу параметрлері енгізілмеген. PostgreSQL тексеруі жеке `demo_ui_checks` дерекқорын пайдаланды; екі SQL іске қосуынан кейінгі тек оқу тексеруінде 24 жоба және 21 тапсырма болды. Бұл сандар тест орындалған сәттегі күйді көрсетеді.

Құрастырулар Debug режимінде сәтті өтті. Жергілікті өзгерістер іске қосу профильдерімен, UserSecretsId және құпиясыз runsettings файлдарымен шектелген; қолданба логикасы мен тест коды өзгермеген. Негізгі релиздің PDF файлдары мен v1.1.0 assets жаңартылмаған.

UI суреттері алынбаған, F9/F10/F11 сценарийлері қолмен орындалмаған. Visual Studio терезесінің қолжетімді мәтінінде негізгі `work/demo-api` көшірмесі көрінді; сурет үшін бөлек `lab01-required-24` шешімі қажет. Терезені түсіру тайм-аутпен аяқталды, қайта қосылуда minimized/user input қателері қайталанды. Браузер қолжетімділігі де бұғатталған. Бұл шектеулер жаңа дәлел алынбайынша жабық тармақ ретінде белгіленбейді.
