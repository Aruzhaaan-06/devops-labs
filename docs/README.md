## Первая лабораторная

- [Подробный разбор, ответы и чек-лист сдачи](lab01.md).
- [Два PDF-отчета и архив исходников](../reports/README.md).
- [Сводки тестов, запросы и скриншоты](../evidence/lab01/README.md).
- [Обязательный этап: 24 теста](https://github.com/Aruzhaaan-06/devops-labs/tree/lab01-required-24). Текущая версия дополнительно проверяет срок новой задачи и содержит 28 тестов.

Для каждой контрольной точки требуется один PDF/DOCX с ФИО, группой, номером задания и подписанными результатами. Отчет второй части включает весь чек-лист сдачи, в том числе действующие или исправленные пункты первой части.

Скриншот коллекции Postman прямо указан в первой сдаче. Во второй нужны подтверждения отладки и Test Explorer. Сохраненные консольные проверки дополняют эти пункты. Порог 70 баллов из итоговой лабораторной 8 нельзя переносить на оценку первой работы: ее оценку определяет преподаватель по ее требованиям.
