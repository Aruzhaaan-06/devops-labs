# Есептер сапасының ішкі аудиті

2026 жылғы 25 қазан. Автоматты түгендеу: **14 зертханалық есеп және 1 қосымша PDF**. Бастапқы жалпы көлем - **119 бет**, түзетілген көлем - **234 бет**. Негізгі жұмыстар саны - 8; бөлімдер жеке есеппен берілген. DOCX/LaTeX түпнұсқалары табылмады. Алғашқы алты есептің Python генераторлары жұмыс каталогында, келесі сегіз есеп пен қосымшаның генераторлары репозиторийде болды; бәрі өңделетін JSON мазмұнына көшірілді.

## Бағалау әдісі және шекарасы

Бұл - пайдаланушы сұраған **ішкі редакторлық шкала**, ГОСТ-тың ресми шкаласы немесе оқытушының бағасы емес. Салмақтар: титул 15, құрылым 20, рәсімдеу 20, қазақ тілі 15, сурет/кесте/сілтемелер 15, қорытынды/әдебиет 10, бет нөмірлері 5.

Қазақ тілінің толық филологиялық сараптамасы орындалмағандықтан, 15 ұпайлық критерий **Тексерілмеді** деп қалдырылды. Сондықтан **100 ұпай бойынша түпкілікті жалпы пайыз есептелмейді**. Төмендегі пайыз тек бағаланған 85 ұпайға нормаланады: `жиналған ұпай / 85 × 100`. Оны толық ГОСТ сәйкестігі немесе тапсырудың толықтығы деп қолдануға болмайды.

Қалған критерийлерге берілген ұпай - нақты көрсетілген фактілерге сүйенген редакторлық пайым; математикалық объективті сертификат емес. Жоқ оқытушы дерегі, тарихи бөлімдердің қайталауы және ұсақ UI мәтіні үшін резерв қалдырылды. 100%-ға жасанды жеткізу қолданылмады.

**14 зертханалық есептің шартты орташа көрсеткіші: 48.0% → 89.2% (тек бағаланған 85 ұпай бойынша). Толық қорытынды пайыз: Тексерілмеді.** Қосымша бұл орташаға кірмейді.

## Репозиторий аудиті

Бастапқы қадағаланатын файлдар саны: 624. Бизнес логикасы, src/tests, Dockerfile, тұрақты Compose және CI/CD workflow косметикалық мақсатта өзгертілмеген. Ескі генератор атаулары бір жинақтаушыға бағытталды; суреттердің қайталануы мазмұн хэшімен бірегейленді.

Тарихи `checks.json`, аударма тексерулері және бұрынғы архивтер - сол кезеңдердің жазбалары; жаңа беттер саны ретінде қолданылмайды. 13-материалдың PDF тексеруі Git-тегі тарихи файлдың байтын тексеретіндей түзетілді. Windows-тағы бір мәтін оқу қатесі анықталып, UTF-8 анық көрсетілді; бастапқы қате жасырылмайды.

Ағымдағы DB құпиясөзінің дәл мәні және кең тараған GitHub токен пішімдері жарияланатын файлдардан ізделді; сәйкестік табылмады. Бұл барлық ықтимал құпияны немесе бүкіл Git тарихын толық сканерлеу емес. `monitoring/compose.yaml` ішінде жергілікті Grafana бастапқы кіру параметрі бар; мәні бұл аудитте қайталанбайды. UI тек loopback-та. Нақты ортаға шығар алдында құпияны бөлек орнату/ауыстыру қажет; осы рәсімдеу жұмысы оны өзгертті деп көрсетілмейді.

Бірдей мазмұнды тарихи журналдар мен өлшем файлдары өшірілмеді: олар әр кезеңнің provenance байланысын сақтайды. `.gitignore` бар; уақытша QA суреттері, жергілікті құпиялар мен орнатылған пакеттер репозиторийге қосылмайды. Ескі орысша техникалық нұсқаулықтар тарихи анықтама ретінде сақталған; жаңадан жасалған пайдаланушы құжаттары мен негізгі навигация қазақша.

- Release құрастыруы сәтті; қазіргі қолданба InMemory 40/40 және бөлек PostgreSQL demo_ui_checks дерекқорында 40/40 тестіден өтті. Негізгі оқу дерекқоры тестке қолданылмады.
- 10-15-материалдардың сақталған дәлел тексерулері орындалды. 13-материалдағы алғашқы Windows кодтау қатесі UTF-8 анық берілгеннен кейін түзетілді; соңғы нәтиже 28/28. 14-материал 30/30, 15-материал 34/34. Бұл ақауларды қайта жасау емес, сақталған дәлелдерді тексеру.
- docker compose config --quiet сәтті; толық құпия мәндері бар config жарияланбады.
- Соңғы PDF автоматты тексеруі 15/15: бос бет, шекарадан шыққан мәтін, жоғалған бастапқы мәтін немесе сурет пикселі табылмады. Қазақ әріптеріне арналған қаріп глифтері тексерілді.
- README және жаңа негізгі құжаттардың 123 жергілікті сілтемесі тексерілді: жоқ нысан 0. 31 бірегей сыртқы URL HTTP 200 қайтарды. Бұл сыртқы беттің мазмұны осы пәнге міндетті екенін растамайды. Development Swagger сілтемесі ортаға тәуелді ретінде бөлек белгіленді.
- Визуалды қарауда титул/мазмұн, кестелердің бөлінуі, сурет пропорциясы, код, нөмір және соңғы беттер тексерілді. Суретке дейінгі ескі қолтаңбаның қайталануы жойылды; қысқа код блоктары бөлінбейтін топқа біріктірілді. UI мәтінін толық оқу үшін түпнұсқа файл сілтемесі сақталған.

Нақты PR/main CI және жариялау нәтижесі релиздегі бөлек соңғы тексеру файлымен бекітіледі. Филологиялық сараптама, оқытушының қабылдауы және ашық тапсыру тармақтары автоматты түрде расталған жоқ.
