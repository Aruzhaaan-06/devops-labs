# Есеп файлдарын тексеру

Есептер UTF-8 JSON бастапқы файлдарынан құрастырылады. Негізгі пішім: A4, Times New Roman 14 pt, 1,5 жол аралығы, сол жақ өріс 30 мм, оң жақ 15 мм, жоғары және төмен 20 мм. Титул жалпы санаққа кіреді, бірақ нөмірі көрсетілмейді.

## Тексеру құрамы

- PDF файлының ашылуы және A4 өлшемі.
- Қазақ әріптері, қаріптердің енгізілуі және мәтіннің бет шекарасында орналасуы.
- Мазмұн, бөлімдер, бет нөмірлері, кестелер және суреттер.
- Бастапқы код блоктарының өзгермеуі және суреттердің түпнұсқа пиксельдері.
- JSON мәтіні мен соңғы PDF мазмұнының сәйкестігі.

```powershell
python scripts/check_reports.py
```

Нақты файлдар, бет саны, SHA-256 және тексеру нәтижелері [quality-check.json](../reports/quality-check.json) ішінде берілген. Беттердің орналасуы PNG көшірмелері арқылы қаралады.
