# GitHub мәтіндерінің қазақша редакциясы

2026 жылғы 25 қазан. Репозиторий: [Aruzhaaan-06/devops-labs](https://github.com/Aruzhaaan-06/devops-labs).

## Редакцияланған материалдар

- Негізгі README, құжаттама навигациясы, жоба құрылымы және PR үлгісі.
- 13 техникалық нұсқаулық және дәлел каталогтарының 14 README файлы. Нұсқаулықтар қазақша редакцияланған есептердің толық мәтініне сүйенеді; бастапқы орындау командалары мен сілтемелері қосымша сақталған.
- 32 issue/PR тақырыбы мен сипаттамасы, 12 белгінің сипаттамасы, 3 бұрынғы релиздің атауы/түсіндірмесі, 24 авторлық ревью және 3 жолдық пікір. Тағы екі issue/PR мен жаңа академиялық релиз бұрыннан қазақша болған. Бір тарихи талқылау пікіріндегі орысша тіркес түзетілген; постмортем қазақша күйінде сақталған.
- GitHub Actions қадам атаулары, tag input сипаттамасы, түсіндірме пікірлер; CODEOWNERS және .env.example түсіндірмелері. Job идентификаторлары, run командалары, шарттар, құқықтар және CODEOWNERS тағайындауы сақталған.

Projects тақтасы иесінің браузер сессиясы арқылы жаңартылды: атауы — «DevOps зертханалық жұмыстары — 4-зертханалық жұмыс», көрінісі — «Тапсырмалар тақтасы». Күй атаулары мен түсіндірмелері: «Жоспарда», «Орындалуда», «Аяқталды». Бар тапсырмалар орындарында сақталған: 1 / 0 / 7; жеті автоматтандыру ережесі қосулы. Тақтадағы тапсырма атаулары issue атауларымен бірге қазақшаланды. GitHub өзі басқаратын Status өрісін қайта атауға рұқсат бермейді; ол жүйелік атау ретінде сақталған. CLI тіркелгісінің project құқығы кеңейтілген жоқ.

## Дәлелдер мен тарихты сақтау

Өткен кезеңнің бет саны, тест саны, SHA, уақыт және күйі қазіргі нәтижемен алмастырылмаған. Бұрынғы PDF/ZIP релиз файлдары мен тегтері өзгермейді. Ревью мәтінін аудару Approve күйін, commit_id, авторын және бастапқы тапсыру уақытын өзгертпейді; редакциялау уақыты GitHub-та жаңарады. Екі ревью аккаунты бір адамға тиесілі екені сақталған.

Код, тесттер, PromQL, мониторинг конфигурациясы, Postman сұраулары, нақты API жауаптары, бастапқы журналдар мен дәлел JSON файлдары аударма үшін өзгертілмейді. Нұсқаулықтағы тарихи код үзінділері `text` блогында көрсетілген; қайталауға арналған түпнұсқа командалар бөлек бөлімде бар. Суреттердегі шынайы интерфейс мәтіні қайта боялмайды.

Git тарихындағы commit хабарламалары, GitHub-тың жүйелік интерфейсі және үшінші тараптың түпнұсқа релиз жазбалары өзгертілмейді. Dependabot PR-ларында қазақша негізгі түсіндірме және жеткізуші жазбалары бар бөлек ашылатын блок берілген; басқару командаларының синтаксисі сақталған. Dependabot кейін PR-ды өзі жаңартса, автоматты мәтінді қайта шығаруы мүмкін.

## Тексеру

Markdown файлдарының UTF-8 мәтіні, жергілікті сілтемелер, бастапқы файлдардың Git мазмұн хэштері және workflow әрекеттерінің сақталуы тексерілді. Құпия мәндер жарияланған жоқ. Міндетті PR CI және main CI/CD нақты GitHub run арқылы тексеріледі; соңғы жариялау қорытындысы нақты run мен main SHA мәнін көрсетеді.
