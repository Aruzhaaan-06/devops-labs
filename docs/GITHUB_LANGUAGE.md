# Репозиторий құжаттамасы

Негізгі README, жұмыс нұсқаулықтары, есептер және каталог түсіндірмелері қазақ тілінде берілген. Docker, PostgreSQL, ASP.NET Core, GitHub Actions, CI/CD, API және PromQL атаулары қалыптасқан жазылымымен қолданылады. Код, командалар, HTTP жауаптары мен журналдар бастапқы пішімінде сақталады.

## Құжаттарды орналастыру

| Каталог | Мазмұны |
|---|---|
| docs/ | Жұмыс нұсқаулықтары және іске қосу тәртібі |
| reports/ | PDF есептері және ортақ архив |
| reports/source/ | Өңделетін JSON файлдары |
| reports/assets/ | Суреттер мен графиктер |
| evidence/ | Журналдар, өлшемдер және тексеру нәтижелері |

## GitHub Projects

Тақта: «DevOps зертханалық жұмыстары — 4-зертханалық жұмыс». Көрініс: «Тапсырмалар тақтасы». Күйлер: «Жоспарда», «Орындалуда», «Аяқталды». Issue және PR нөмірлері өзгермейді; жабылған тапсырмалар автоматтандыру арқылы аяқталған күйге өтеді.
