# Есептерді рәсімдеу

Есептерге A4 пішімі мен бірыңғай құрылым қолданылды. Рәсімдеу негізі ретінде ГОСТ 7.32-2017 алынды; негізгі мәтінге Times New Roman 14 pt таңдалды.

## Есеп құрылымы

Титул, мазмұн, жұмыстың мақсаты, теориялық мәліметтер, орындау барысы, нәтижелер, талдау, қорытынды және пайдаланылған әдебиеттер. Қорытынды есепте жұмыстардың жалпы нәтижелері жинақталған.

## Бастапқы файлдар

Мәтін `reports/source/` каталогындағы UTF-8 JSON файлдарында, суреттер `reports/assets/` каталогында сақталады. Код, HTTP жауаптары, SHA және тәжірибе уақыттары бастапқы мәндерімен берілген.
