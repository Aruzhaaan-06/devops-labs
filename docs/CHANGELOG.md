# Құжаттама өзгерістері

## 2026-10-25 — GitHub мәтіндерін қазақшалау

- 13 техникалық нұсқаулық қазақша редакцияланған есептердің толық мазмұны негізінде жаңартылды; бастапқы орындау командалары мен сілтемелері сақталды.
- Дәлел каталогтарының 14 README файлы, жоба құрылымы және PR үлгісі қазақшаға сәйкестендірілді. Журналдар, өлшем JSON файлдары және суреттер өзгерген жоқ.
- GitHub-тағы тапсырмалар, PR сипаттамалары, авторлық ревью мәтіндері, ескі релиз түсіндірмелері мен белгі сипаттамалары қазақшаланды; нөмірлер, күй, уақыттар және бастапқы техникалық нәтижелер сақталады.
- GitHub Actions ішіндегі тек қадам атаулары, input сипаттамасы және түсіндірме пікірлер аударылды; job идентификаторлары, run командалары, шарттар мен құқықтар өзгермейді.
- Өнім берушілердің түпнұсқа жазбалары, Dependabot басқару командалары, код және Git тарихы қайта жазылмайды. Ескі релиз файлдары алмастырылмайды.


## 2026-10-25 - Академиялық рәсімдеуді біріздендіру

- 14 зертханалық есеп пен бір қосымша автоматты түрде түгенделді; бұрынғы 119 бет тарихи бастапқы нұсқа ретінде тіркелді.
- Әр PDF үшін өңделетін JSON бастапқы файлы жасалды. 1281 бастапқы мазмұн блогы көшірілді; код блоктары мен 28 бірегей активтің түпнұсқа байттары сақталған.
- Times New Roman 14 pt, 1,5 интервал, A4 және 30/15/20/20 мм өрістермен ортақ жинақтаушы қосылды. Титул, автоматты мазмұн, бөлімдер, нөмірлер, сурет/кесте/листинг атаулары және әдебиеттер біріздендірілді.
- Қазақша түсіндірмелердегі терминдер мен жекелеген грамматикалық құрылымдар редакцияланды. Код, уақыттар, HTTP жауаптары және сурет мазмұны аударма үшін өзгертілмеді.
- README мен есептер каталогы қазақша қайта жазылды; нормативтік негіз, толықтық шектері және ішкі аудит қосылды.
- PDF ашылуы, A4, мәтін шекарасы, қаріп, бөлім, нөмір, мазмұн және сурет пиксельдері үшін автоматты тексеру енгізілді.
- Бұрынғы генератор атаулары ортақ жинақтаушыға бағытталды. 13-материалдың тарихи PDF тексеруі жаңа рәсімдеуді бұрынғы файл хэшімен шатастырмай, Git-тегі түпнұсқаны тексереді.

Бұл редакция қолданбаның бизнес логикасын, HTTP келісімін, тұрақты Compose конфигурациясын, CI/CD workflow немесе тәжірибе журналдарын өзгертпейді. UI суреттері, қолмен жөндеу және қорғау орындалды деп белгіленбейді. Алдыңғы PDF нұсқалары Git тарихында және бұрынғы релиз файлдарында сақталған.
