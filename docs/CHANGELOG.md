# Өзгерістер тарихы

## 2026-10-25

- Есептердегі мақсат, орындау барысы, нәтижелер, талдау және қорытынды біріздендірілді.
- Бағалау кестелері, қорғауға арналған жоспарлар және жұмыс мазмұнына қатысы жоқ қызметтік түсіндірмелер алынып тасталды.
- Барлық PDF қайта құрастырылды; өңделетін бастапқы файлдар сақталды.
- Техникалық нұсқаулықтар мен есеп каталогы жаңартылды.

## Негізгі шығарылымдар

- v0.1.0 — жоба атауын өзгерту және PR арқылы жұмыс істеу.
- v1.0.0 — CI/CD, бейнені жариялау, орналастыру және кері қайтару.
- v1.1.0 — инцидентті анықтау, қалпына келтіру және жауап уақытын тексеру.

Нұсқалардың коды мен бұрынғы файлдары Git тарихында сақталған.
