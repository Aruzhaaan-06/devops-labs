## Құрал шектеулері

Бұрынғы тексеруде браузер құралы `Local browser use is disabled in Work settings`, Windows сурет түсіру құралы `FrameArrived timed out` қатесін берді. Осы рәсімдеу жұмысы жаңа UI суреті алынған немесе жөндегіш қолмен орындалған деп мәлімдемейді. Ескі дәлелдер толық ажыратымдылықтағы файлдарымен сақталған.

Ұсақ интерфейс мәтіні A4 ішіндегі суретте қиын оқылуы мүмкін. Әр сурет жанында түпнұсқа файлды толық ажыратымдылықта ашу сілтемесі бар. Суреттер қиылмаған, қайта боялмаған немесе жасанды жазумен толықтырылмаған. Инцидент графигі нақты Prometheus деректерінен жасалған график ретінде белгіленген; UI скриншоты емес.

## Титул және ресми қабылдау

Оқытушының аты-жөні, кафедра және студенттің нақты оқытушысын бекітетін құжат берілмеген. Оларға арналған жалған мәндер енгізілмеді. Ашық ШҚТУ пәні бетіндегі оқытушыларды осы студенттің оқытушысы деп қабылдауға негіз жоқ.

2025-2026 оқу жылы - пайдаланушы берген дерек. Тәжірибелердің 2026 жылғы қазандағы нақты уақыттары өзгертілмеген. Қажет болса, оқу жылын оқытушымен нақтылау керек.

ГОСТ ғылыми-зерттеу есебіне арналған. Осы жинақтың барлық параметрі нақты DevOps пәніне міндетті екенін немесе оқытушы қабылдағанын мәлімдемейміз. Қазақ тілінің толық филологиялық сараптамасы да автоматты тексерумен алмастырылмайды.
