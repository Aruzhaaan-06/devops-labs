# Жұмыстарды тапсыруға дайындау

ВКТУ · Есімханова Аружан Түсіпханқызы · 25-ИСТК-2о.

Күйі: 2026 жылғы 25 қазан. Бұл құжат орындалған жұмыстарды қайта орындау үшін емес, тапсыруға жетіспейтін дәлелдер мен ұйымдастыру қадамдарын аяқтау үшін берілген. [Он төрт есеп, 116 бет](../reports/README.md) және [v1.1.0 релизі](https://github.com/Aruzhaaan-06/devops-labs/releases/tag/v1.1.0) жарияланған. Барлық тармақ толық жабылды деп мәлімделмейді.

## Қайта тексерілген дайындық

- Бірінші жұмыс үшін `lab01-required-24` тегінің `f93b1234fc09eb70b1010f566c0c8282ac55d336` нұсқасы бөлек жұмыс каталогына дайындалды. Қойма — InMemory, мекенжай — `http://localhost:8094`. Міндетті **24/24 тест** командалық жолда қайта өтті.
- Үшінші жұмыс үшін `lab03-postgres` тегінің `890b3546ae9b18179e36509d7552dd4e4182d8f7` нұсқасы дайындалды. Мекенжай — `http://localhost:8095`, жеке дерекқор — `demo_ui_checks`. Міндетті **24/24**, толық жиынтық **28/28** өтті. Екі нәтиже бөлек сақталды.
- Қосылу құпиясы Git-ке енгізілмей, жергілікті .NET User Secrets арқылы берілген. Негізгі `demo` дерекқоры қолданылмаған; тексеру үшін бөлек дерекқор пайдаланылған.

Бұл нәтижелер Test Explorer суретінің немесе жөндегішті қолмен пайдаланудың орнына жүрмейді. Visual Studio терезесін түсіру тайм-аутпен аяқталды; қайта қосылуда `window is minimized` және `user input was detected` қателері қайталанды. Браузер құралы `Local browser use is disabled in Work settings` қатесін қайта берді.

## Екі сұрауды жөндегіште орындау

Алдымен негізгі `work/demo-api` көшірмесінің орнына бөлек `lab01-required-24/DemoApi.slnx` шешімін ашу керек. Debug конфигурациясын және `http` профилін таңдап, F5 арқылы іске қосу қажет. Test Explorer-дегі 24 тестіні осы шешімде орындау керек.

1. Postman-да жаңа жоба мен екі бөлек Todo тапсырма құру. Қайтарылған нақты идентификаторларды пайдалану.
2. `TasksController.ChangeStatus`, `TaskService.GetAsync`, `TaskService.ChangeStatusAsync`, `InMemoryTaskRepository.GetAsync` және `SetStatusAsync` әдістеріне F9 арқылы үзу нүктелерін қою. Locals және Call Stack терезелерін ашу.
3. Бірінші тапсырмаға `PATCH /api/tasks/<id>/status`, денесі `{"status":"Done"}` сұрауын жіберу. F10/F11 арқылы контроллер → сервис → репозиторий → контроллер жолын бақылау. `CanTransition(Todo, Done)` — false; 409 жауабын контроллер таңдайды. Жаңарту әдістері шақырылмайды.
4. Екінші Todo тапсырмаға денесі `{"status":"InProgress"}` сұрауын жіберу. Бұл жолы `ChangeStatusAsync` → `SetStatusAsync` → `Replace` шақырылады; жаңартылған мән контроллерге қайтып, жауап 200 болады.
5. Сұрау үзу нүктесінде тоқтап тұрған кезде Postman-дағы күту күйін қате деп қабылдамау. Жөндегішті жалғастырғаннан кейін нақты HTTP жауабын сақтау. Тәжірибеден кейін Shift+F5 арқылы тек осы бөлек процесті тоқтату.

Қадамдарды орындап, Locals/Call Stack-ті көргеннен кейін ғана қолмен жөндеу тармағы орындалды деп белгіленеді.

## PostgreSQL интерфейсіндегі тексеру

Бөлек `lab03-postgres/DemoApi.slnx` шешімін ашу керек. `http` профилі localhost:8095 және Postgres режиміне дайындалған. F5 кезінде `Хранилище: PostgreSQL` жазуын түсіру қажет.

Міндетті тестілер үшін шешімнің түбіріндегі `postgres-required24.runsettings`, толық жиынтық үшін `postgres-full28.runsettings` файлын Test Explorer конфигурациясына таңдау керек. Бірінші файл мерзімге қатысты қосымша төрт жағдайды сүзеді; екіншісі барлық 28 жағдайды орындайды. Құпия қосылу жолын редакторда немесе кадрда ашудың қажеті жоқ.

## Инциденттің тарихи көрінісі

Нақты инцидент 2026 жылғы 24 қазанда болды: T0 — 18:10:54 UTC, T1 — 18:14:18.726 UTC, T2 — 18:15:58.875 UTC. Жергілікті уақыт — UTC+5. UI арқылы сол деректерді кейін ашу түпнұсқа оқиға кезіндегі скриншотқа тең емес; суретке «тарихи деректердің кейін ашылған көрінісі» деген түсіндірме беріледі.

- Grafana: DemoApi дашбордында уақытты **2026-10-24 18:10–18:24 UTC** аралығына бекіту, `Latency p95` панелін көрсету. Браузер жергілікті белдеуді қолданса, бұл 23:10–23:24 аралығы.
- Prometheus графигі: `ALERTS{alertname="ApiSlowRequests",alertstate="firing"}` сұрауын сол уақытқа ашу.
- Tasks/List бойынша p95 үшін сақталған сұрау: `histogram_quantile(0.95, sum by (le,controller,action) (rate(http_request_duration_seconds_bucket{job="demo-api"}[1m])))`.
- Prometheus деректерді жеті күн сақтауға бапталған; нақты қолжетімділік сақталған томға байланысты. Тарих UI-да жоқ болса, [сақталған JSON деректерін](../evidence/lab08-incident/README.md) пайдалану керек. Графикті қолдан жасап, UI суреті деп көрсетуге болмайды.

Сурет алу үшін ақаулы релиз қайта орнатылмайды. Қазіргі latency gate әдейі енгізілген 1500 мс кідірісті deploy кезінде анықтайды.

## Оқытушының немесе студенттің қатысуын қажет ететін тармақтар

- Оқытушының GitHub атауын алып, репозиторийге қолжетімділік беру.
- Екі аккаунт бір адамға тиесілі екенін ескертіп, жұптық жұмыстың орнына осы техникалық сценарийді қабылдауды оқытушымен келісу. Тәуелсіз топтас студенттің ревьюі орындалды деп есептелмейді.
- Жеке B репозиторийіндегі кезең үшін оқытушымен келісу: пайдаланушы барлық жұмысты бір репозиторийде жинауды таңдаған, сондықтан бұл кезең автоматты түрде жабылмайды.
- 04-материалдың тапсырмасы берілсе, оны бөлек салыстыру. Қазір оның шарты жоқ; тапсырманың жоқтығы орындалғанын білдірмейді.
- Курс форумында қорғау уақытына жазылу, 10 минуттық онлайн қорғауда экранды көрсету және екі сұраққа жауап беру, есептерді СДО-ға жүктеу.

Кеңейтілген performance baseline [#30](https://github.com/Aruzhaaan-06/devops-labs/issues/30) осы толықтырудың құрамына кірмейді. Алдымен жоғарыдағы тапсыру тармақтары аяқталады.
